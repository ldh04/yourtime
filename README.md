# 너의 시간 ⏰

멀리 있는 소중한 사람의 시간을 폰 상태바에 띄워주는 안드로이드 앱이에요.
장거리 연애, 해외에 사는 가족과 친구, 시차가 있는 누구에게나.

## 다운로드

**[📥 최신 버전 받기 (APK)](https://github.com/ldh04/yourtime/releases/latest/download/yourtime.apk)**

이전 버전은 [Releases](https://github.com/ldh04/yourtime/releases)에서 볼 수 있어요.

> 안드로이드 8.0 이상에서 쓸 수 있어요. 아이폰은 지원하지 않아요.

## 이런 걸 할 수 있어요

- **상태바 시계** · 폰 맨 위에 상대 시간 아이콘이 항상 떠요.
  - 오전은 빈 모양, 오후는 꽉 찬 모양이라 한눈에 구분돼요.
  - 미니 시계, 해·달, 하트, 동그라미 중에서 골라요.
- **떠 있는 미니 시계** · 다른 앱 위에 컬러 시계를 띄워요. 끌어서 원하는 곳에 둘 수 있어요. (선택)
- **여러 사람 등록** · 연인, 엄마, 친구를 모두 넣고, ★ 한 명을 상태바에 띄워요.
- **37개 나라, 지역별 시간** · 미국이나 호주처럼 지역마다 시간이 다른 나라도 정확해요. 서머타임은 자동으로 반영돼요.
- **다음 만남 D-day**

## 설치 방법

1. 위의 **최신 버전 받기**를 폰에서 눌러 파일을 받아요.
2. 받은 파일을 열어요.
3. "출처를 알 수 없는 앱" 경고가 뜨면 **설정 → 이 출처 허용**을 켜고 돌아와서 **설치**를 눌러요.
4. 앱을 열고 **+ 사람 추가**로 상대 이름과 나라를 넣어요.
5. **상태바에 켜기**를 누르고 알림을 허용하면 끝!

## 업데이트

새 버전을 받아서 그대로 설치하면, 설정은 그대로 두고 업데이트돼요.

## 잘 안 될 때

- **상태바에 아이콘이 안 보여요** · 설정 → 알림 → 상태 표시줄 → 알림 아이콘 표시를 **모두**로 바꿔 주세요.
- **가끔 시계가 사라져요** · 설정 → 애플리케이션 → 너의 시간 → 배터리 → **제한 없음**으로 바꿔 주세요.
- **미니 시계가 안 떠요** · 앱에서 스위치를 켤 때 나오는 "다른 앱 위에 표시"를 허용해 주세요. 상태바 시계가 켜져 있어야 함께 떠요.

## 개인정보

이 앱은 인터넷을 쓰지 않아요. 이름, 나라 같은 설정은 폰 안에만 저장되고 어디로도 보내지 않아요.
